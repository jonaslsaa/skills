
# Agent Skills
A collection of custom agent skills that I use.


- **commit-msg** — Generate a commit message for uncommitted changes. Extracts JIRA ticket from branch name, validates branch context, follows repo commit style.

  ```
  npx skills@latest add jonaslsaa/skills/commit-msg
  ```

- **fix-use-effects** — Identify and fix unnecessary `useEffect` usage in React components.

  ```
  npx skills@latest add jonaslsaa/skills/fix-use-effects
  ```

- **tanstack-start** — TanStack Start framework patterns and best practices. Includes 18 reference docs covering routing, server functions, middleware, SSR, auth, hydration errors, and more.

  ```
  npx skills@latest add jonaslsaa/skills/tanstack-start
  ```

- **componentize** — Break up large React files into well-organized components. Pragmatic extraction with clear placement rules — avoids over-splitting.

  ```
  npx skills@latest add jonaslsaa/skills/componentize
  ```

- **frontend-design**

  ```
  npx skills@latest add https://github.com/anthropics/skills --skill frontend-design
  ```
